# Issue tracker: Local Markdown

This project has no Git remote. Keep current implementation and production checkpoints in `PROGRESS.md`.
When a separate issue or PRD is needed, use `.scratch/<feature>/issues/<NN>-<slug>.md` and `.scratch/<feature>/PRD.md`.
Record triage as a `Status:` line using the vocabulary in `triage-labels.md`. Do not publish externally without user instructions.
